# Memory and retention

User preferences and inferred memories have separate provenance and revisions. They are not authoritative CRM facts. Memory can be disabled globally or for a new conversation. Deleting a conversation removes its chat retrieval and cancels active work; explicit saved memories remain until separately deleted. Audit/approval records may be retained by the shared manager. No ChatGPT history or memory import is implemented. Company guidance is editable by authorized managers with new revisions and rollback-by-new-revision.
