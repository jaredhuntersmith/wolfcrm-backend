# Funding, staff allocations and usage

Personal API credentials remain encrypted at rest and are managed only through the authenticated native settings flow. The assistant cannot read/change keys, grant itself capabilities or allocate funding. Model and funding never switch silently. A ChatGPT subscription is not API funding; hosted ChatGPT-plan access requires the provider’s separate approved integration.

The actual company owner can allocate, revise or revoke a monthly owner-funded staff limit in Assistant settings. Staff also need their own enabled assistant execution/tools, current company permissions and personal monthly/run limits. An allocation grants no tool capability. Owner-funded spend reserves against company, staff allocation, user and run limits before the provider call. Revocation blocks subsequent work; personal funding is not selected as a fallback. Uncertain provider usage remains reserved for review.

Usage displays provider-reported input/cached/output tokens, supported web searches, estimated cost, reservations and current UTC-month limit. It is an estimate, not the provider invoice or account balance. File processing token preflight and web research use the explicitly selected model/funding source. API configuration, Meta approval and receiver credentials remain owner configuration; internal operations do not depend on inventing credentials.
