# AI tasks in Automations

Read automation_catalog for real trigger and schedule fields. Create a draft, read its graph hash, save typed trigger/assistant.task/end nodes, inspect the result, and publish only with the exact graph hash and authorized policy. AI task config includes publishing execution_user_id, instructions, allowed_tools, verified model/reasoning, max_steps, estimated max_cost_micros, output_destination, output_title and failure_behavior. AI tasks cannot invoke automation control tools or native navigation. Existing scheduler/event deduplication and timezone/DST behavior apply. The action waits durably without advancing through approval. Each result is in its own conversation; private_note/company_note delivery uses note_create and its configured approval. Cancellation of the parent stops subsequent assistant work. Failure appears in the existing automation run/issues; error_path supports a separately authorized notification branch.
