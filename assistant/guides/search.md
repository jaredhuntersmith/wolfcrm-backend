# Search and private records

Use entity filters, exact terms, dates, relationships and every relevant pagination cursor. Leads are contact records. Customer SMS bodies are customer_messages; use conversation_id to retrieve their thread. Comms membership and history cutoffs apply. Notes full-text and reference search is available through notes_search_filtered. Private Notes and Ideas remain private even to company administrators. File metadata is distinct from content: only explicitly supported file formats can be read. No whole-database upload, image extraction, audio transcription or semantic vector index is implied.
